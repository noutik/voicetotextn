# voicetotextn

Голосовой ввод для Wayland. Нажми **Super+A**, говори, нажми **Super+A** ещё раз — текст появится в поле ввода, где стоит курсор. Всё работает без интернета, на видеокарте или процессоре, через [whisper.cpp](https://github.com/ggml-org/whisper.cpp).

## Возможности

- **Одна клавиша.** Первое нажатие начинает запись и показывает сверху экрана маленький чёрно-белый эквалайзер. Второе — распознаёт речь, копирует текст в буфер обмена и вставляет его.
- **Без интернета.** Whisper large-v3-turbo (q8_0) через whisper.cpp: на видеокарте (Vulkan), когда она свободна, иначе на процессоре. Ни звук, ни текст не покидают компьютер.
- **Смесь языков.** Крошечная модель Whisper, пока ты говоришь, выбирает язык диктовки из короткого списка (по умолчанию русский или английский); первый язык списка побеждает, если модель не слышит явно другой. Английские слова внутри русской речи остаются латиницей: *«Запусти Docker Compose и проверь Git статус»*.
- **Ничего не висит в памяти между диктовками.** Программа запускается по нажатию и грузит модель, пока ты уже говоришь, — слова не теряются.
- **Escape отменяет** запись.
- **Вставляет почти везде.** Текст кладётся и в буфер обмена, и в «выделение» (primary selection), потом программа нажимает Shift+Insert: так вставка работает в браузерах, GTK/Qt-программах и терминалах вроде kitty.

## Скорость

Время распознавания (`voicetotextn transcribe`), Radeon RX 9070 XT и Ryzen 7 7800X3D (8 потоков). После второго нажатия микрофон работает ещё 0.25 с, чтобы поймать конец последнего слова, поэтому на видеокарте ожидание на столько же больше. На процессоре распознавание начинается на паузе, ещё до клавиши, и ожидание обычно меньше, чем в таблице (см. ниже).

| Речь  | Видеокарта | Процессор |
|-------|------------|-----------|
| 5 с   | 0.2–0.4 с  | ~1.1 с    |
| 10 с  | 0.2–0.4 с  | ~1.9 с    |
| 13 с  | 0.2–0.4 с  | ~2.6 с    |
| 20 с  | 0.2–0.4 с  | ~4.1 с    |
| 27 с  | 0.2–0.4 с  | ~6.2 с    |

На видеокарте: около 1.2 ГБ видеопамяти во время диктовки. На процессоре: около 1.9 ГБ памяти (1.1 ГБ с `VOICETOTEXTN_BF16=0`). Ноль в остальное время.

На процессоре распознавание не ждёт клавиши: оно начинается после 0.4 с тишины, поэтому пауза перед вторым нажатием вычитается из ожидания. 15 тестовых записей по 14–30 с, проигранных как диктовки (`transcribe --live`), дали тот же текст, что и раньше, а ждать пришлось в среднем 3.4 с вместо 3.8 с: примерно на 1 с меньше после паузы больше секунды, нисколько после паузы в 4 с, столько же без паузы.

`VOICETOTEXTN_PARTS=10` идёт дальше: для речи от 10 с текст, сделанный на паузе, остаётся, даже если ты говоришь дальше, и после остановки распознаётся только последняя часть. Среднее ожидание на тех же записях упало до 1.8 с. Но части распознаются без контекста друг друга, и от текста полного окна отличалось 11.7% слов вместо 2.9% — в основном это фальстарты, которые Whisper выбрасывает, когда слышит продолжение. Поэтому по умолчанию это выключено.

Обычно Whisper всегда обрабатывает окно в 30 с, даже для фразы из двух слов. Видеокарта так и делает: полное окно стоит ей долей секунды и даёт лучший текст. На процессоре полное окно занимает 5–6 с, поэтому voicetotextn сужает его до длины речи плюс 3 с тишины, но не меньше 10 с. Это стоит точности: на 483 тестовых клипах текст тем чаще расходился с полным окном, чем короче было окно, а всего с 1 с тишины Whisper дописывал выдуманные или повторённые слова к 15% клипов.

## Что нужно

- Linux с Wayland-композитором, который поддерживает **wlr-layer-shell**, **wlr-data-control** и **virtual-keyboard-unstable-v1**. Разработано и проверено на [niri](https://github.com/YaLTeR/niri); Sway, Hyprland и другие композиторы на wlroots дают те же протоколы. GNOME не поддерживается.
- PipeWire (с pipewire-pulse) или PulseAudio.
- Масштаб экрана 1: плашка рисуется в 1× и пока не учитывает HiDPI.

## Установка

### 1. Сборка

Нужны: Rust 1.85+, cmake, компилятор C/C++, clang (libclang), pkg-config, заголовки libpulse и, для видеокарты, заголовки Vulkan и компилятор шейдеров `glslc`.

```sh
# Arch
sudo pacman -S --needed rust cmake clang pkgconf libpulse vulkan-headers vulkan-icd-loader shaderc
# Debian / Ubuntu (Rust через https://rustup.rs, если в пакетах старше 1.85)
sudo apt install cmake clang libclang-dev pkg-config libpulse-dev libvulkan-dev glslc
```

```sh
git clone https://github.com/noutik/voicetotextn
cd voicetotextn
cargo build --release
install -Dm755 target/release/voicetotextn ~/.local/bin/voicetotextn
```

Сборка без поддержки видеокарты (Vulkan не нужен ни для сборки, ни для запуска, всегда процессор): `cargo build --release --no-default-features`.

whisper.cpp собирается с `-march=native`, то есть под процессор, на котором идёт сборка. Готовые сборки (только для процессора) — на странице [Releases](https://github.com/noutik/voicetotextn/releases), обе для glibc 2.43+ (Arch и другие «плавающие» дистрибутивы): `x86_64-linux` — для любого x86-64 с AVX2, `x86_64-avx512bf16-linux` — для процессоров с AVX512-BF16 (AMD Zen 4 и новее, Intel Xeon начиная с Sapphire Rapids), примерно в 1.4 раза быстрее первой. На остальных системах собирай из исходников.

### 2. Модели

```sh
mkdir -p ~/.local/share/voicetotextn && cd ~/.local/share/voicetotextn
curl -LO https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q8_0.bin  # 874 МБ
curl -LO https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny.bin                 # 78 МБ
```

### 3. Горячая клавиша

niri (`~/.config/niri/config.kdl`, внутри `binds`):

```kdl
Mod+A hotkey-overlay-title="Voice to text" { spawn "voicetotextn"; }
```

Sway: `bindsym $mod+a exec voicetotextn` · Hyprland: `bind = SUPER, A, exec, voicetotextn`

Если `~/.local/bin` нет в `PATH` композитора, укажи полный путь (`/home/ты/.local/bin/voicetotextn`).

## Как пользоваться

| Клавиша | Действие |
|---------|----------|
| Super+A | начать запись — говорить можно сразу |
| Super+A ещё раз | распознать и вставить |
| Escape (во время записи) | отменить, ничего не вставится |

Во время записи плашка держит клавиатуру, чтобы поймать Escape. После второго нажатия фокус возвращается в твоё окно, и текст вставляется туда.

## Настройки

Переменные окружения, например в niri: `spawn "env" "VOICETOTEXTN_LANG=de,en" "voicetotextn";`

| Переменная | По умолчанию | Что делает |
|------------|--------------|------------|
| `VOICETOTEXTN_LANG` | `ru,en` | Список через запятую: маленькая модель выбирает один язык на диктовку — первый, если другому она не даёт хотя бы 0.5. Один код (`ru`) — язык всегда один. `auto` — Whisper сам определяет любой язык, но это лишний полный проход большой модели (примерно в 2 раза медленнее). |
| `VOICETOTEXTN_MODEL` | `~/.local/share/voicetotextn/ggml-large-v3-turbo-q8_0.bin` | Основная модель. |
| `VOICETOTEXTN_DETECTOR` | `~/.local/share/voicetotextn/ggml-tiny.bin` | Модель для выбора языка. |
| `VOICETOTEXTN_GPU` | `auto` | `auto` — видеокарта, когда она свободна, иначе процессор. `0` — всегда процессор. `1` — видеокарта при любой загрузке. |
| `VOICETOTEXTN_MIN_WINDOW` | `10` | Наименьшее окно на процессоре в секундах; `30` — полное окно Whisper. |
| `VOICETOTEXTN_AHEAD` | `1` | На процессоре распознавание начинается на каждой паузе в 0.4 с, и его текст идёт в дело, если до остановки больше ничего не сказано. `0` — начинать только после остановки. |
| `VOICETOTEXTN_PARTS` | — | На процессоре: от скольких секунд речи (например, `10`) текст, сделанный на паузе, остаётся, когда ты говоришь дальше, — тогда после остановки распознаётся только последняя часть. Быстрее на длинных диктовках, но менее точно: см. [Скорость](#скорость). |
| `VOICETOTEXTN_THREADS` | число физических ядер | Потоки whisper.cpp. |
| `VOICETOTEXTN_PROMPT` | — | Подсказка (initial prompt) для Whisper. |
| `VOICETOTEXTN_FLASH` | `1` | `0` выключает flash attention. |
| `VOICETOTEXTN_BF16` | `1` | `0` — turbo-модель на процессоре как есть, без BF16-копии: 1.1 ГБ памяти вместо 1.9 ГБ, но медленнее. |
| `VOICETOTEXTN_SAVE_DIR` | — | Сохранять каждую запись туда в WAV (для тестов). |
| `VOICETOTEXTN_DRY_RUN` | — | Распознать, но не вставлять. |

## Как устроено

- Каждое нажатие запускает программу. Первый экземпляр становится сессией и слушает абстрактный unix-сокет; следующий только подключается к нему («переключить») и выходит.
- Звук: 16 кГц моно с микрофона по умолчанию (PulseAudio/PipeWire) — ровно то, с чем работает Whisper.
- Плашка: поверхность layer-shell на верхнем слое, рисуется программно (сглаженные фигуры) в общую память. Столбики — спектр по FFT на 1024 точки, низкие частоты слева.
- Распознавание: пока ты говоришь, маленькая модель выбирает язык по уже записанному. После второго нажатия микрофон работает ещё 0.25 с (клавишу обычно нажимают на хвосте последнего слова), тишина в начале и в конце обрезается, и turbo-модель распознаёт. На процессоре она не ждёт клавиши: после 0.4 с тишины распознаёт всё сказанное к этому моменту. Если ты говоришь дальше, этот проход прерывается, а его текст отбрасывается; если нет, текст тот же, каким был бы после остановки, только раньше. Проход идёт в копии процесса (fork): whisper.cpp не умеет останавливаться посреди кодировщика, а процесс можно убить сразу. Записи длиннее 30 с распознаются с временными метками, чтобы слова не терялись на стыках 30-секундных окон Whisper. Фраза, которую Whisper повторяет по кругу (три и более слов трижды подряд или пять и более дважды), остаётся один раз.
- Видеокарта: дискретная карта используется через Vulkan, когда на ней свободно хотя бы 2 ГБ памяти и она загружена меньше чем на 90% (загрузка известна только для карт AMD, от amdgpu); иначе, или если карта дала сбой, работает процессор. Модели занимают около 1.2 ГБ видеопамяти на время диктовки.
- BF16: на процессорах с AVX512-BF16 (AMD Zen 4 и новее, Intel Xeon начиная с Sapphire Rapids) whisper.cpp перемножает BF16-матрицы быстрее, чем Q8_0 (кодировщик на Zen 4 работает в 1.25–1.4 раза быстрее), поэтому при первом запуске turbo-модель переводится в BF16 в `~/.cache/voicetotextn` (1.6 ГБ, около секунды). Из готовых сборок эти ядра есть только в `x86_64-avx512bf16-linux`; сборка для AVX2 использует модели как есть.
- whisper.cpp собирается с матричными ядрами llamafile (`GGML_LLAMAFILE`, задано в `.cargo/config.toml`).
- Вставка: wlr-data-control кладёт текст в буфер обмена и в «выделение» (фокус клавиатуры не нужен), виртуальная клавиатура нажимает Shift+Insert. Процесс продолжает отдавать текст (несколько МБ памяти), пока другая программа не займёт буфер.
- Журнал: `~/.local/state/voicetotextn.log` (только тайминги, распознанный текст не пишется).

Инструменты для разработки: `voicetotextn transcribe FILE.wav…` распознаёт WAV 16 кГц и печатает время (язык выбирается до замера, как в сессии во время речи); с `--live` перед файлами проигрывает их со скоростью речи, как идёт диктовка, и печатает ожидание после конца; `voicetotextn demo WAV START SECONDS DIR` рисует кадры анимации, что выше.
