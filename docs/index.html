Говори — и текст уже в поле ввода

Нажми Super+A, говори, нажми ещё раз. voicetotextn распознаёт речь без интернета, прямо на процессоре, и вставляет текст туда, где стоит курсор.

Скачать Инструкция

Что умеет

Одна клавиша

Первое нажатие — запись и маленький эквалайзер сверху экрана. Второе — текст в буфере обмена и в поле ввода.

Без интернета

Whisper large-v3-turbo через whisper.cpp на CPU. Звук и текст не покидают компьютер.

Русский и английский вперемешку

Маленькая модель за 0.25 с выбирает язык. «Запусти Docker Compose» — английские слова остаются латиницей.

Ничего не висит в памяти

Программа стартует по нажатию, модель грузится, пока ты уже говоришь. Слова не теряются.

Вставка почти везде

Буфер обмена + «выделение» + Shift+Insert: браузеры, GTK/Qt, терминалы вроде kitty.

Escape — отмена

Передумал — Escape во время записи, и ничего не вставится.

Скорость

Установка

  1. Собери программу (нужны Rust 1.85+, cmake, clang, pkg-config, libpulse) или скачай готовую из Releases: 
    git clone https://github.com/noutik/voicetotextn
cd voicetotextn && cargo build --release
install -Dm755 target/release/voicetotextn ~/.local/bin/voicetotextn
  2. Скачай модели (874 МБ + 78 МБ): 
    mkdir -p ~/.local/share/voicetotextn && cd ~/.local/share/voicetotextn
curl -LO https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q8_0.bin
curl -LO https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny.bin
  3. Повесь на клавишу. niri: 
    Mod+A hotkey-overlay-title="Voice to text" { spawn "voicetotextn"; }
    Sway: bindsym $mod+a exec voicetotextn · Hyprland: bind = SUPER, A, exec, voicetotextn

Нужен Wayland-композитор с wlr-layer-shell, wlr-data-control и virtual-keyboard (niri, Sway, Hyprland…) и PipeWire или PulseAudio. GNOME не поддерживается.

Speak, and the text is already in the input field

Press Super+A, speak, press it again. voicetotextn transcribes offline, right on the CPU, and pastes the text where your cursor is.

Download Documentation

Features

One hotkey

First press: recording and a small equalizer at the top of the screen. Second press: the text lands in the clipboard and in the input field.

Offline

Whisper large-v3-turbo through whisper.cpp on the CPU. No audio or text leaves your computer.

Mixed languages

A tiny model picks the language in 0.25 s (Russian or English by default, configurable). English terms inside Russian speech stay in Latin script.

Nothing in memory

Starts on the key press and loads the model while you are already speaking. No words are lost.

Pastes almost everywhere

Clipboard + primary selection + Shift+Insert: browsers, GTK/Qt apps, terminals such as kitty.

Escape cancels

Changed your mind? Escape while recording, nothing is pasted.
